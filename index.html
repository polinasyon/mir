Amac

Bu sayfa, branch feature/scaffold-v2-1'de yaptığım değişiklikleri ve nasıl test edileceğini hızlıca gösterir. Sen (arıcı) index.html üzerinden ne eklendiğini görebilirsin; istersen ben PR açıp değişiklikleri main'e merge edebilirim.

Eklenen dosyalar (kısa)

  • src/main.js — uygulamayı başlatan ESM giriş noktası
  • src/app.js — scaffold integrator (uygulama ile pedigree modülünü bağlar)
  • src/api-client.js — fotoğrafı model endpoint'ine POST eden küçük wrapper (mock destekli)
  • src/pedigree.js — UI: floating buton + modal, fotoğraf yükleme ve sonucu kovana kaydetme
  • data/floraveritabani.sample.json — örnek flora verisi
  • data/bolgeharitasi.sample.json — örnek bölge haritası
  • docs/PEDIGREE.md — Pedigree akışı ve FastAPI notları
  • README.md, LICENSE, .gitignore

Dosyaların ham hallerini görmek için bağlantılar:

  • src/pedigree.js

Hızlı test — Yerelde

  1. Repo'yu klonla (veya zaten klonluysa fetch yap): 
    git clone https://github.com/polinasyon/mir.git
cd mir
git fetch origin
git checkout feature/scaffold-v2-1
  2. Basit bir HTTP sunucusu başlat (örnek): 
    python -m http.server 8000
    Sonra tarayıcıda http://localhost:8000 aç.
  3. Sayfa yüklendiğinde uygulamanın sağ alt köşesinde turuncu "Pedigree" butonu göreceksin. Butona tıkla, kovan seç, fotoğraf yükleyip Gönder'e bas; mock model yanıtı dönecek ve kovan verisine kaydetme denenecek.

Not: Eğer gerçek Hugging Face FastAPI endpoint'in varsa bana URL ver; gerçek POST entegrasyonunu ekleyeyim.
